Notes

Browser tools are static files and can be served by GitHub Pages or any local static server. The Web Player and TVA-loading samples currently import JSZip from a CDN.

TVA format version 0.1.0 stores monochrome UTF-8 plain-text frames. Color layers, canvas rendering, and media export are future work.
